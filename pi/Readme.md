# Pi

[Pi agent](https://pi.dev/) configuration.

## Extensions

| Name | Description |
| --- | --- |
| [block-destructive-operations](agent/extensions/block-destructive-operations.ts) | Ask for permission before running destructive shell commands. |
| [lint-format-on-write](agent/extensions/lint-format-on-write.ts) | Run Oxlint and Oxfmt after file edits and writes. |
| [pretty](agent/extensions/pretty.ts) | Customize tool rendering, user prompts, turn separators, and the footer. |
| [session-name](agent/extensions/session-name.ts) | Name new sessions from their first prompt using the cheapest available model. |
| [web-tools](agent/extensions/web-tools.ts) | Search the web with DuckDuckGo and extract web pages as Markdown with Trafilatura. |
| [whimsical](agent/extensions/whimsical.ts) | Animate the working indicator with whimsical status messages. |
