# Configuration, documentation, and agent artifacts

## Configuration

Invented or undocumented keys, speculative options for environments that do not exist, duplicated settings already defined elsewhere, values that contradict related config in the repo, and secrets or credentials committed in plain text.

## Documentation

Comments or prose that narrate structure instead of conveying non-obvious intent; duplicated instructions already in the base prompt, `AGENTS.md`, or parent docs; setup steps that do not match the repo; placeholder or sample values presented as production guidance; formatting or heading churn unrelated to the substance of the change.

## Scope and churn

Unrelated refactors, speculative sections, generated-file or lockfile churn, and formatting changes not produced or required by the repository formatter.
