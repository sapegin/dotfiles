# Desktop and native UI

Local visual and markup slop in native chrome. Prefer the smallest fix inside the selected scope.

## Aesthetic and control slop

- One-off chrome that fights nearby surfaces in the same diff: oversized corner radii, frosted glass, flat transparent pill rows, or marketing/plugin-store styling in utility shells.
- Custom-drawn widgets where an existing system control in the surrounding code already fits.
- Copied title-bar, border, or panel drawing pasted beside a shared shell the project already uses.
- Spacing or control density that reads mobile-scale next to AppKit-norm neighbors in the same surface.
